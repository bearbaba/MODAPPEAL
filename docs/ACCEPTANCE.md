# Verification & remaining gaps

## Local acceptance
- Persistent SQLite posts, cases and event history
- Frozen, hashed evidence with versioned rule and both parties' statements
- Exact quotation check and explicit **manual fixture** decision
- ALLOW_REVISION creates a new snapshot and requires a second decision
- Stale-version veto, unique execution key, post readback and replay safety
- Responsive loopback UI and three HTTP acceptance scenarios
- Continuous integration via GitHub Actions (Node 24)

## Not yet certified
- GenLayer contract/consensus/transaction hashes
- Wallet signature login and production role authorization
- Discourse API integration and sandbox readback
- External-write outbox and provider timeout reconciliation
- Browser E2E and deployed pilot with real community users

These gaps block an honest 9/10 evaluation. No private content is posted on chain in this local demo.
